🎬 CineScope – Movie Analytics Dashboard

An interactive Movie Analytics Dashboard built using Python and Streamlit to explore, analyze, and visualize movie industry data.

📌 Project Overview

CineScope is a data analytics project that helps users explore movie datasets through an interactive dashboard. It provides insights into movie budgets, revenue, runtime, genres, production companies, languages, and audience ratings.

🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- Openpyxl

📊 Dataset Information

The project uses an Excel dataset containing movie-related information, including:

- Movie ID and Title
- Release Date and Status
- Budget and Revenue
- Runtime
- Genres and Production Companies
- Spoken and Original Languages
- Vote Average and Vote Count
- Population and Adult Classification

✨ Project Goals

- Explore movie industry data.
- Analyze movie budgets and revenue.
- Understand movie ratings and audience engagement.
- Visualize movie-related information through interactive charts.
- Practice Python-based data analytics.

🚀 How to Run Locally

1. Clone this repository.
2. Install the required libraries:

pip install -r requirements.txt

3. Keep the Excel dataset in the same folder as "app.py".
4. Run the dashboard:

streamlit run app.py
